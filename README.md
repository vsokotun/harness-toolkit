The default `CLAUDE.md` is intended as a starting point for greenfield projects.

It provides a small set of general project-level instructions to use before the codebase has developed its own conventions, constraints, and project-specific guidance.

As the project matures, these defaults are expected to be replaced or overridden by rules derived from the actual codebase and team practices.

The file is adapted from the community `andrej-karpathy-skills` project, with many negatively framed instructions rewritten as positive behavioral guidance.
